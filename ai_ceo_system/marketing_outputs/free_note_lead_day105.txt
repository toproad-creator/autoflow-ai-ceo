「商談・社内会議の文字起こし要約＆タスク自動割り振り」に毎月どれくらいの時間を使っていますか？

実務の現場では、次のようなロスが起きやすい業務です。
・商談や会議の録音を文字起こししても、結局読み返す時間がなく「言った言わない」のトラブルが減らない

・1時間の会議に対して、要約とタスク整理に30分〜1時間かかっており、コア業務を圧迫している

1つひとつの確認作業は15分でも、積み重なると月平均で約26時間（時給2,800円換算で【年間 約873,600円相当】）を消費します。この記事では、ChatGPT・Geminiなどで即使える専用プロンプトだけでなく、Googleスプレッドシート上で通知・記録まで自動化するGAS完成コードもそのまま無料公開します。

■ 2. コピペで使える！「商談・社内会議の文字起こし要約＆タスク自動割り振り」専用・実務プロンプト
以下をそのままコピーして、対象データを貼り付けて実行してください（[要確認]フラグで人の目チェックが必要な行だけを浮き彫りにします）。

```text
### 役割
あなたは超一流のプロジェクトマネージャー兼秘書です。提供される「商談・会議の文字起こし原文」を解析し、実務に直結する形式で要約とタスク抽出を行ってください。

### 厳守判定基準
1. 要約は「背景」「決定事項」「保留事項」の3点に絞り、箇条書きで簡潔に記述すること。
2. タスク抽出では「誰が」「いつまでに」「何を」するかを明確にすること。
3. 担当者が不明な場合は [要確認]、期限が不明な場合は [期限未定] と明記すること。
4. 専門用語や社内用語は文脈から推測し、不自然な変換ミスは修正して記載すること。
5. 感情的な発言は排除し、事実とアクションのみを抽出すること。

### 出力フォーマット（以下の形式を厳守）
【要約】
・背景：...
・決定事項：...
・保留事項：...

【タスク一覧】
1. [担当者] 内容（期限：YYYY/MM/DD）

### 入力例
「えーと、佐藤さんが来週の月曜までに資料を直して、それを僕がチェックしてクライアントに送ります。あ、期限は水曜まででいいかな」
↓
【タスク一覧】
1. [佐藤] 資料の修正（期限：来週月曜）
2. [発言者] 資料のチェックおよびクライアント送付（期限：来週水曜）
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const OPENAI_API_KEY = 'YOUR_API_KEY'; // OpenAIのAPIキーを設定

  for (let i = 1; i < data.length; i++) {
    const [date, title, rawText, summary, tasks, status] = data[i];
    if (status === '完了' || !rawText) continue;

    try {
      const prompt = `以下の文字起こしを要約し、タスクを抽出してください。\n\n${rawText}`;
      const response = UrlFetchApp.fetch('https://api.openai.com/v1/chat/completions', {
        method: 'post',
        headers: {
          'Authorization': `Bearer ${OPENAI_API_KEY}`,
          'Content-Type': 'application/json'
        },
        payload: JSON.stringify({
          model: 'gpt-4o-mini',
          messages: [
            {role: 'system', content: 'あなたは優秀なPMです。指定されたプロンプトに従い要約とタスク抽出を行ってください。'},
            {role: 'user', content: prompt}
          ]
        })
      });

      const result = JSON.parse(response.getContentText()).choices[0].message.content;
      const [resSummary, resTasks] = result.split('【タスク一覧】');

      sheet.getRange(i + 1, 4).setValue(resSummary.replace('【要約】', '').trim());
      sheet.getRange(i + 1, 5).setValue(resTasks ? resTasks.trim() : 'タスクなし');
      sheet.getRange(i + 1, 6).setValue('完了');

      MailApp.sendEmail({
        to: 'your-email@example.com',
        subject: `【自動通知】${title} の要約・タスク抽出が完了しました`,
        body: `会議名: ${title}\n\n要約:\n${resSummary}\n\nタスク:\n${resTasks}`
      });

    } catch (e) {
      sheet.getRange(i + 1, 6).setValue('エラー: ' + e.message);
    }
  }
}
```

■ 4. 現場導入でつまずかない2つのポイント＆無料診断ツール
・文字起こしデータが極端に長い（数万文字）場合、OpenAI APIのトークン制限やGASの実行時間制限（6分）に抵触します。解決策として、10分単位で分割して処理するか、GPT-4o-miniなどの軽量モデルを選択してください。
・「これ」「あれ」といった指示語が多い会議体では、AIが主語を誤認するケースがあります。解決策として、プロンプトに『文脈から主語を補完せよ』という指示を追加し、さらにスプレッドシート側に「参加者リスト」の列を設けてAIに参照させると精度が劇的に向上します。
