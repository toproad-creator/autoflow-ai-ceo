実務の現場では、次のようなロスが起きやすい業務です。
・レスポンシブ検索広告（RSA）の見出し15本を毎回捻り出すのが苦痛で、クリエイティブな思考が停止している

・LPの内容と広告文の整合性を保ちつつ、クリック率（CTR）を高めるための「問いかけ」や「ベネフィット」の出し分けが属人化している

1つひとつの確認作業は15分でも、積み重なると月平均で約21時間（時給2,900円換算で【年間 約730,800円相当】）を消費します。この記事では、ChatGPT・Geminiなどで即使える専用プロンプトだけでなく、Googleスプレッドシート上で通知・記録まで自動化するGAS完成コードもそのまま無料公開します。

■ 2. コピペで使える！「Google広告・Meta広告の検索見出し15本＆説明文一括ジェネレーター」専用・実務プロンプト
以下をそのままコピーして、対象データを貼り付けて実行してください（[要確認]フラグで人の目チェックが必要な行だけを浮き彫りにします）。

```text
あなたは獲得効率を最大化させる運用型広告専門のシニアコピーライターです。
以下の制約条件を厳守し、Google広告・Meta広告用の広告文を生成してください。

### 入力データ
- 商材名：{A列}
- 訴求軸：{B列}
- 必須キーワード：{C列}

### 厳守ルール
1. 見出し(Headline): 厳密に15本生成すること。全角15文字（半角30文字）以内を絶対死守。
2. 説明文(Description): 厳密に4本生成すること。全角45文字（半角90文字）以内を絶対死守。
3. 重複禁止: 15本すべて異なる訴求（価格、品質、信頼、限定性、悩み解決等）にバラけさせること。
4. 記号制限: 「！」「？」は1つまで。使用不可記号（【】、◎、※）は絶対に使わないこと。
5. 必須キーワード: C列の単語を必ず3本以上の見出しに含めること。

### 出力形式（JSON形式のみ）
{
  "headlines": ["見出し1", "見出し2", ... "見出し15"],
  "descriptions": ["説明文1", ... "説明文4"]
}

### 例外処理
文字数制限をどうしても超える場合は、意味が通じる範囲で省略し、[要確認]というフラグを末尾に付けてください。
出力はJSON以外の解説テキストを一切含めないでください。
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const API_KEY = 'YOUR_OPENAI_API_KEY';
  const API_URL = 'https://api.openai.com/v1/chat/completions';

  for (let i = 1; i < data.length; i++) {
    const [product, point, keyword, status] = [data[i][0], data[i][1], data[i][2], data[i][3]];
    if (status === '完了' || !product) continue;

    try {
      const prompt = `商材:${product}, 訴求:${point}, キーワード:${keyword} に基づき広告文を生成せよ。`; // 詳細はexpert_prompt参照
      const payload = {
        model: 'gpt-4o',
        messages: [{role: 'system', content: '広告コピーライターとしてJSONで回答します。'}, {role: 'user', content: prompt}],
        response_format: { type: 'json_object' }
      };

      const response = UrlFetchApp.fetch(API_URL, {
        method: 'post',
        contentType: 'application/json',
        headers: { Authorization: 'Bearer ' + API_KEY },
        payload: JSON.stringify(payload)
      });

      const result = JSON.parse(response.getContentText());
      sheet.getRange(i + 1, 5).setValue(JSON.stringify(result.choices[0].message.content));
      sheet.getRange(i + 1, 4).setValue('完了');
      sheet.getRange(i + 1, 6).clearContent();
    } catch (e) {
      sheet.getRange(i + 1, 4).setValue('エラー');
      sheet.getRange(i + 1, 6).setValue(e.toString());
    }
  }
  MailApp.sendEmail(Session.getActiveUser().getEmail(), '広告文生成ジョブ完了', 'スプレッドシートの生成が完了しました。確認してください。');
}
```
