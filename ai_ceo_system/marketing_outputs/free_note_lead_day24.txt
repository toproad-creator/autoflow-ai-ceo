■ 2. コピペで使える！「アルバイト・スタッフの希望シフト回収＆スプレッドシート自動編成」専用・実務プロンプト
以下をそのままコピーして、対象データを貼り付けて実行してください（[要確認]フラグで人の目チェックが必要な行だけを浮き彫りにします）。

```text
あなたは熟練の店舗マネージャー兼データアナリストです。以下のルールに基づき、アルバイトのシフト希望データを厳格に精査してください。

【前提役割】
入力されたシフト希望が、店舗の運営ルールに合致しているかを1行ずつ判定し、不備があれば[要確認]フラグを立てる役割を担います。

【厳守判定基準】
1. 勤務時間は最短3時間以上、最長8時間以内であること。
2. 休憩時間：6時間を超える勤務の場合、45分以上の休憩が確保されているか（入力値から自動計算）。
3. 深夜労働：22時以降の勤務が含まれる場合、18歳未満のスタッフでないか（スタッフ名簿との照合を想定）。
4. 形式チェック：日付が「YYYY/MM/DD」、時刻が「HH:mm」形式であること。

【出力列の定義】
- 判定結果：OK または [要確認]
- 理由：不備がある場合、その具体的な内容（例：勤務時間が短すぎます）
- 修正案：推奨されるシフト時間の提案

【例外時の[要確認]ルール】
- 希望時間が店舗営業時間（09:00-22:00）を逸脱している場合は即座に[要確認]とする。
- 同一スタッフから同日に重複した申請がある場合は、最新のタイムスタンプを優先する。

【入力例】
スタッフ名: 田中太郎, 希望日: 2023/10/25, 開始: 10:00, 終了: 12:00
→判定結果: [要確認], 理由: 勤務時間が3時間未満です。
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const header = data.shift(); // ヘッダーを除去
  
  const adminEmail = "your-email@example.com"; // 管理者のメールアドレス
  let processedCount = 0;
  let errorLogs = [];

  data.forEach((row, index) => {
    const rowIndex = index + 2; // スプレッドシートの行番号に合わせる
    const staffName = row[1];
    const date = row[2];
    const startTime = row[3];
    const endTime = row[4];
    const status = row[5];

    // すでに処理済みの行はスキップ
    if (status === "完了" || status === "エラー") return;

    try {
      // 必須項目の入力チェック
      if (!staffName || !date || !startTime || !endTime) {
        throw new Error("必須項目が未入力です");
      }

      // ロジック：簡易的な時間計算（実務ではDateオブジェクトで詳細比較）
      const start = new Date(`2000/01/01 ${startTime}`);
      const end = new Date(`2000/01/01 ${endTime}`);
      const diffHours = (end - start) / (1000 * 60 * 60);

      if (diffHours <= 0) throw new Error("終了時刻が開始時刻より前です");

      // ステータス更新
      sheet.getRange(rowIndex, 6).setValue("完了");
      sheet.getRange(rowIndex, 6).setBackground("#d9ead3"); // 薄緑
      processedCount++;

    } catch (e) {
      sheet.getRange(rowIndex, 6).setValue("エラー");
      sheet.getRange(rowIndex, 6).setBackground("#f4cccc"); // 薄赤
      errorLogs.push(`行 ${rowIndex}: ${e.message}`);
    }
  });

  // 完了通知の送信
  if (processedCount > 0 || errorLogs.length > 0) {
    const body = `シフト自動チェックが完了しました。\n\n処理件数: ${processedCount}件\nエラー件数: ${errorLogs.length}件\n\n${errorLogs.join("\n")}`;
    MailApp.sendEmail(adminEmail, "【自動通知】シフトチェック実行結果", body);
  }
}
```
