■ 2. コピペで使える！「請求書・領収書PDFのAI読取＆スプレッドシート記帳」専用・実務プロンプト
以下をそのままコピーして、対象データを貼り付けて実行してください（[要確認]フラグで人の目チェックが必要な行だけを浮き彫りにします）。

```text
あなたは熟練の経理担当者として、提供された画像またはPDFから正確にデータを抽出してください。

### 厳守ルール:
1. 以下の項目をJSON形式で出力してください：date(YYYY/MM/DD), company, amount, tax_rate, invoice_number, category, memo
2. 「合計金額」は税込価格を数値のみで抽出してください。
3. 「インボイス登録番号」は T+13桁の番号を探し、存在しない場合は「なし」と記載してください。
4. 「勘定科目」は、内容から推測される一般的な科目（会議費、旅費交通費、消耗品費等）を割り当ててください。
5. 以下の場合は、memo欄に [要確認] と記載し、理由を添えてください：
   - 文字が掠れていて数字の判読に自信がない場合
   - 領収書ではなく「見積書」や「請求書」が混在している場合
   - 金額の合計と内訳が計算上合わない場合
6. 出力はJSONデータのみとし、解説文は一切不要です。

### 入力例に対する期待値:
- 発行日: 2023年10月5日 -> 2023/10/05
- 取引先: ｶﾌﾞｼｷｶﾞｲｼｬ ｻﾝﾌﾟﾙ -> 株式会社サンプル
- 金額: ￥1,100 (内消費税100円) -> 1100
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const API_KEY = 'YOUR_GEMINI_API_KEY'; // Gemini API Key
  const API_URL = 'https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=' + API_KEY;

  for (let i = 1; i < data.length; i++) {
    let [status, fileName, , , , , , , driveLink] = data[i];
    if (status !== '未処理' || !driveLink) continue;

    try {
      const fileId = driveLink.split('id=')[1] || driveLink.split('/d/')[1].split('/')[0];
      const fileBlob = DriveApp.getFileById(fileId).getBlob();
      const base64Data = Utilities.base64Encode(fileBlob.getBytes());

      const payload = {
        'contents': [{
          'parts': [
            { 'text': sheet.getRange('A1').getNote() || 'Extract invoice data to JSON' },
            { 'inline_data': { 'mime_type': fileBlob.getContentType(), 'data': base64Data } }
          ]
        }]
      };

      const response = UrlFetchApp.fetch(API_URL, {
        'method': 'post',
        'contentType': 'application/json',
        'payload': JSON.stringify(payload)
      });

      const result = JSON.parse(response.getContentText());
      const aiText = result.candidates[0].content.parts[0].text.replace(/```json|```/g, '');
      const json = JSON.parse(aiText);

      sheet.getRange(i + 1, 1, 1, 10).setValues([[
        '完了',
        fileName,
        json.date,
        json.company,
        json.amount,
        json.tax_rate,
        json.invoice_number,
        json.category,
        driveLink,
        json.memo
      ]]);

    } catch (e) {
      sheet.getRange(i + 1, 1).setValue('エラー');
      sheet.getRange(i + 1, 10).setValue(e.toString());
    }
  }
  MailApp.sendEmail(Session.getActiveUser().getEmail(), '【自動化通知】記帳処理が完了しました', 'スプレッドシートを確認してください。');
}
```
