### 厳守判定基準
1. 【ターゲット】は「誰の、どんな深い悩みか」を心理的背景まで含めて言語化すること。
2. 【ベネフィット】は機能の羅列ではなく、そのサービスを使った後の「感情的変化」を記述すること。
3. 【弱点】は、顧客が抱くであろう「一歩引いた視点での懸念（例：価格が高い、実績が不明確など）」を特定すること。
4. 【ABテスト案】は、競合の弱点を逆手に取った「勝てる仮説」と「具体的なキャッチコピー案」をセットで提示すること。

[ベネフィット]：
[エビデンス]：
[弱点]：
[ABテスト案]：

- 訴求軸が複数混在し、1つに絞れない場合は、最も強調されているメイン訴求を優先し、サブ訴求を「[要確認] 複数訴求あり」として追記してください。

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const apiKey = PropertiesService.getScriptProperties().getProperty('OPENAI_API_KEY');
  
  for (let i = 1; i < data.length; i++) {
    const [url, , , , , , status] = data[i];
    if (status === '完了' || !url) continue;

    try {
      // LPのテキスト情報を取得（簡易スクレイピング）
      const response = UrlFetchApp.fetch(url, { muteHttpExceptions: true });
      const html = response.getContentText();
      const textContent = html.replace(/<[^>]+>/g, ' ').substring(0, 3000); // 3000文字制限

      const prompt = `あなたはプロのLPO担当者です。以下のLPを分析してください。\nURL: ${url}\n内容: ${textContent}`;
      
      const payload = {
        model: "gpt-4-turbo",
        messages: [{ role: "user", content: prompt }],
        temperature: 0.7
      };

      const apiResponse = UrlFetchApp.fetch("https://api.openai.com/v1/chat/completions", {
        method: "post",
        headers: { "Authorization": "Bearer " + apiKey, "Content-Type": "application/json" },
        payload: JSON.stringify(payload)
      });

      const result = JSON.parse(apiResponse.getContentText()).choices[0].message.content;
      const parsedData = parseResult(result);

      sheet.getRange(i + 1, 2, 1, 5).setValues([parsedData]);
      sheet.getRange(i + 1, 7).setValue('完了');
      
    } catch (e) {
      sheet.getRange(i + 1, 7).setValue('エラー: ' + e.message);
    }
  }
  MailApp.sendEmail(Session.getActiveUser().getEmail(), "【自動化完了】競合LP分析レポート", "スプレッドシートの更新が完了しました。");
}

function parseResult(text) {
  const tags = ['[ターゲット]', '[ベネフィット]', '[エビデンス]', '[弱点]', '[ABテスト案]'];
  return tags.map(tag => {
    const start = text.indexOf(tag) + tag.length + 1;
    const end = tags[tags.indexOf(tag) + 1] ? text.indexOf(tags[tags.indexOf(tag) + 1]) : text.length;
    return text.substring(start, end).trim();
  });
}
```
