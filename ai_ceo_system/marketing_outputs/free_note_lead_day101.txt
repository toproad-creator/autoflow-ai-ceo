「ECショップの発送連絡・返品問い合わせAI自動一次返信」に毎月どれくらいの時間を使っていますか？

実務の現場では、次のようなロスが起きやすい業務です。
・セールや繁忙期に「いつ届くか」という配送状況の確認メールが殺到し、CS担当者が1日中コピペ作業に追われる。
・返品希望の理由（初期不良 vs 自己都合）の仕分けミスが発生し、返送送料の負担を巡って顧客とトラブルになる。
・深夜や休日の問い合わせに対して一次返信が遅れ、ショップのレビュー評価（レスポンスの速さ）が低下する。

1つひとつの確認作業は15分でも、積み重なると月平均で約29時間（時給2,200円換算で【年間 約765,600円相当】）を消費します。この記事では、ChatGPT・Geminiなどで即使える専用プロンプトだけでなく、Googleスプレッドシート上で通知・記録まで自動化するGAS完成コードもそのまま無料公開します。

■ 2. コピペで使える！「ECショップの発送連絡・返品問い合わせAI自動一次返信」専用・実務プロンプト
以下をそのままコピーして、対象データを貼り付けて実行してください（[要確認]フラグで人の目チェックが必要な行だけを浮き彫りにします）。

```text
### 前提役割
あなたは国内大手ECショップのカスタマーサポート統括責任者です。丁寧かつ迅速な一次返信案を作成してください。

### 厳守判定基準
1. 【発送連絡の場合】注文番号・配送番号が入力されているか確認し、配送状況確認URL（https://example.com/track?id=）に番号を付与して案内すること。
2. 【返品希望の場合】理由が「初期不良・誤送」なら「着払い（店舗負担）」、「自己都合（サイズ違い・イメージ違い等）」なら「元払い（お客様負担）」と明確に区別して案内すること。
3. 【禁止事項】返金金額の確定、謝罪クーポン発行の約束、在庫確保の確約は絶対に行わないこと。

### 例外時の[要確認]ルール
以下に該当する場合は、返信案の冒頭に「[要確認]」と記載し、スタッフへ引き継ぐ文言のみ出力してください。
- 著しく攻撃的な言動やクレームが含まれる場合
- 配送事故（破損）の報告がある場合
- 過去に何度も同様の問い合わせがある場合

### 出力形式
- 宛名：〇〇様
- 挨拶と感謝の言葉
- 結論（配送状況または返品手順）
- 結びの言葉
- 署名：ECショップサポートチーム

### 入力例
顧客名：{{顧客名}}
内容：{{お問い合わせ内容}}
番号：{{注文・配送番号}}
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const OPENAI_API_KEY = 'YOUR_API_KEY'; // 実際のAPIキーを設定してください

  for (let i = 1; i < data.length; i++) {
    const [timestamp, customerName, inquiry, orderId, draft, status] = data[i];

    // ステータスが「未処理」の場合のみ実行
    if (status === '未処理') {
      try {
        const prompt = `以下の情報を元に返信案を作成してください。\n顧客名：${customerName}\n内容：${inquiry}\n番号：${orderId}`;
        
        const response = UrlFetchApp.fetch('https://api.openai.com/v1/chat/completions', {
          method: 'post',
          headers: {
            'Authorization': `Bearer ${OPENAI_API_KEY}`,
            'Content-Type': 'application/json'
          },
          payload: JSON.stringify({
            model: "gpt-4o",
            messages: [
              {role: "system", content: "あなたはECショップのCS担当です。プロンプトの指示に従い返信案を作成してください。"},
              {role: "user", content: prompt}
            ]
          })
        });

        const aiReply = JSON.parse(response.getContentText()).choices[0].message.content;
        
        // シートへの書き込み（AI返信案とステータス更新）
        sheet.getRange(i + 1, 5).setValue(aiReply);
        
        if (aiReply.includes('[要確認]')) {
          sheet.getRange(i + 1, 6).setValue('要確認');
        } else {
          // 自動送信（テスト時はコメントアウト推奨）
          // MailApp.sendEmail('customer@example.com', 'お問い合わせの件につきまして', aiReply);
          sheet.getRange(i + 1, 6).setValue('送信済');
        }

      } catch (e) {
        console.error('Error at row ' + (i + 1) + ': ' + e.toString());
        sheet.getRange(i + 1, 6).setValue('エラー発生');
      }
    }
  }
}
```
