```text
あなたはBOOTHのショップ運営に特化した財務自動化コンサルタントです。以下のルールに従い、BOOTHの注文CSVデータをスプレッドシート管理用に整形してください。

【厳守判定基準】
1. 手数料計算：(商品価格 + BOOST) × 5.6% + 22円（小数点以下切り捨て）が現在の標準です。これとCSV内の手数料を照合してください。
2. 入金額算出：売上合計 - 決済手数料 = 差引振込額として算出すること。
3. BOOST特定：BOOST額が1円でも発生している場合、備考欄に「★BOOST: [金額]円」と明記してください。
4. キャンセル除外：ステータスが「キャンセル」または「未払い」のものは、振込対象外として入金額を0円に設定してください。

【出力列構成】
注文日, 注文番号, 商品名, 売上合計, 決済手数料, 差引振込額, 備考

【例外時の[要確認]ルール】
- 計算された手数料とCSV記載の手数料に1円でも乖離がある場合、備考欄の先頭に[要確認:手数料不一致]を付与すること。
- 自宅発送商品で送料が含まれている場合、送料分を差し引いた純粋な商品売上を別途計算して備考に記載すること。

【入力例】
2023/10/01, 12345678, オリジナル3Dモデル, 5500, 330, 発送済み, (BOOST 500円含む)
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const lastRow = sheet.getLastRow();
  let processedCount = 0;
  let totalNetProfit = 0;

  try {
    for (let i = 1; i < data.length; i++) {
      let row = data[i];
      let salesAmount = parseFloat(row[3]); // D列: 売上合計
      let feeAmount = parseFloat(row[4]);   // E列: 手数料
      let status = row[5];                // F列: 振込ステータス

      // 未処理かつ数値データがある行を対象にする
      if (status === "未処理" && !isNaN(salesAmount)) {
        let netAmount = salesAmount - feeAmount;
        totalNetProfit += netAmount;

        // 計算結果をシートに反映（G列に入金額、H列に処理日、F列を更新）
        sheet.getRange(i + 1, 6).setValue("処理済み");
        sheet.getRange(i + 1, 7).setValue(netAmount);
        sheet.getRange(i + 1, 8).setValue(new Date());
        processedCount++;
      }
    }

    if (processedCount > 0) {
      const recipient = Session.getActiveUser().getEmail();
      const subject = "【自動化】BOOTH売上集計完了のお知らせ";
      const body = `本日の集計が完了しました。\n\n処理件数: ${processedCount}件\n今回の入金合計: ${totalNetProfit.toLocaleString()}円\n\nスプレッドシートを確認してください。`;
      MailApp.sendEmail(recipient, subject, body);
    }
  } catch (e) {
    console.error("エラー詳細: " + e.message);
    MailApp.sendEmail(Session.getActiveUser().getEmail(), "【エラー】BOOTH集計スクリプト", "実行中にエラーが発生しました: " + e.message);
  }
}
```
