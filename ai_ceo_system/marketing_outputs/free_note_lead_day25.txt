```text
あなたは地域密着型店舗のブランドマネージャー兼、MEO対策の専門家です。以下の制約条件を厳守し、Googleマップの口コミに対する「返信案」を作成してください。

### 役割と目的
・投稿者への感謝を伝え、リピート率を向上させる。
・未訪問のユーザーに対し、店舗の魅力（清潔感、技術力、接客）をアピールする。
・自然な形で「店舗名」と「主要サービス名」を1回ずつ含め、MEO効果を高める。

### 厳守判定基準
1. 星4以上：ポジティブな内容を強調し、再来店を促す温かい文章を作成せよ。
2. 星3：中立的な意見として受け止め、改善への意欲を示しつつ感謝を述べよ。
3. 星1〜2：【要確認】と冒頭に記載し、返信案は作成せず「至急、店長による事実確認と個別対応が必要です」と出力せよ。
4. 本文なし（星のみ）：来店への感謝を簡潔に述べ、次回はぜひ感想を聞かせてほしい旨を伝えよ。

### 出力形式
・150文字〜250文字程度。親しみやすくも礼儀正しい敬語（です・ます調）。
・[要確認]ルールに該当する場合は、その理由も短く添えること。

### 入力データ例
・店舗名：あおぞら整体院
・主要サービス：骨盤矯正
・投稿者：{{レビュアー名}}
・評価：{{星評価}}
・本文：{{口コミ本文}}
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const OPENAI_API_KEY = 'YOUR_API_KEY_HERE';
  const NOTIFY_EMAIL = 'your-email@example.com';

  for (let i = 1; i < data.length; i++) {
    const [date, name, rating, content, currentReply, status] = data[i];
    if (status === '完了' || status === '確認中') continue;

    try {
      const prompt = `店舗名:あおぞら整体院, サービス:骨盤矯正, 名前:${name}, 評価:${rating}, 本文:${content}`;
      const response = callOpenAI(prompt, OPENAI_API_KEY);
      
      sheet.getRange(i + 1, 5).setValue(response);
      
      if (response.includes('[要確認]')) {
        sheet.getRange(i + 1, 6).setValue('確認中');
        MailApp.sendEmail(NOTIFY_EMAIL, '【要確認】低評価口コミが入りました', `行番号: ${i + 1}\n内容: ${content}`);
      } else {
        sheet.getRange(i + 1, 6).setValue('生成済み');
      }
    } catch (e) {
      console.error('Error at row ' + (i + 1) + ': ' + e.toString());
      sheet.getRange(i + 1, 6).setValue('エラー発生');
    }
  }
}

function callOpenAI(prompt, apiKey) {
  const url = 'https://api.openai.com/v1/chat/completions';
  const options = {
    method: 'post',
    contentType: 'application/json',
    headers: { Authorization: 'Bearer ' + apiKey },
    payload: JSON.stringify({
      model: 'gpt-4o',
      messages: [{ role: 'system', content: 'あなたはMEO専門家です。' }, { role: 'user', content: prompt }]
    })
  };
  const res = UrlFetchApp.fetch(url, options);
  return JSON.parse(res.getContentText()).choices[0].message.content;
}
```
