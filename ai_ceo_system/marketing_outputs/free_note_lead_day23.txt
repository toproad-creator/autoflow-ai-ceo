■ 2. コピペで使える！「Amazon・楽天の競合商品レビュー分析＆改善アイデア抽出」専用・実務プロンプト
以下をそのままコピーして、対象データを貼り付けて実行してください（[要確認]フラグで人の目チェックが必要な行だけを浮き彫りにします）。

```text
あなたは10年以上のキャリアを持つ製品開発コンサルタントです。入力された競合商品のレビュー原文を分析し、自社商品の優位性を築くための改善案を抽出してください。

【厳守判定基準】
1. 「配送が早い」「梱包が丁寧」といった物流面の評価は、製品改善に寄与しないため無視すること。
2. 「壊れやすい」「重い」といった抽象的な表現は、可能な限り「どの部位が」「何g以下なら許容されるか」を文脈から推測して具体化すること。
3. 感情的な批判ではなく、機能・性能・デザイン・価格の4観点で論理的に分析すること。

【出力列と形式】
- 不満の核心：ユーザーが最もストレスを感じているポイントを15文字以内で要約。
- 具体的改善案：自社商品で採用すべきスペック変更や新機能を、エンジニアが理解できるレベルで記述。
- 優先度判定：[高・中・低]の3段階。安全性や基本機能に関わる不満は[高]とする。

【例外時の[要確認]ルール】
- レビューが10文字未満、または「特になし」等の無意味な内容の場合は、全項目に[要確認: 情報不足]と出力してください。
- 外国語のレビューが混入している場合は、日本語に翻訳した上で分析を行ってください。

【入力例】
商品名：ワイヤレスイヤホン
レビュー原文：音質は良いが、30分のランニングで耳から落ちそうになる。シリコンの質感が滑りやすい気がする。
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const apiKey = PropertiesService.getScriptProperties().getProperty('OPENAI_API_KEY');
  const apiUrl = 'https://api.openai.com/v1/chat/completions';

  for (let i = 1; i < data.length; i++) {
    const [productName, reviewText, status] = data[i];
    if (status === '完了' || !reviewText) continue;

    try {
      const prompt = `以下のレビューを分析してください。\n商品名：${productName}\nレビュー：${reviewText}`;
      const payload = {
        model: 'gpt-4o-mini',
        messages: [
          { role: 'system', content: 'あなたは製品開発コンサルタントです。JSON形式で回答してください。キーは "core_pain", "improvement", "priority" です。' },
          { role: 'user', content: prompt }
        ],
        response_format: { type: 'json_object' }
      };

      const response = UrlFetchApp.fetch(apiUrl, {
        method: 'post',
        contentType: 'application/json',
        headers: { Authorization: `Bearer ${apiKey}` },
        payload: JSON.stringify(payload)
      });

      const result = JSON.parse(response.getContentText());
      const content = JSON.parse(result.choices[0].message.content);

      sheet.getRange(i + 1, 3, 1, 4).setValues([[
        '完了',
        content.core_pain,
        content.improvement,
        content.priority
      ]]);
      
      SpreadsheetApp.flush();
    } catch (e) {
      sheet.getRange(i + 1, 3).setValue('エラー: ' + e.message);
    }
  }

  MailApp.sendEmail({
    to: Session.getActiveUser().getEmail(),
    subject: '【自動化完了】競合レビュー分析が終了しました',
    body: 'スプレッドシートを確認してください。'
  });
}
```
