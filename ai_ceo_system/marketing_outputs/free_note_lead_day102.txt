# 厳守判定基準

- 140文字で収めるには情報量が多すぎる場合

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const apiKey = PropertiesService.getScriptProperties().getProperty('OPENAI_API_KEY');
  const promptTemplate = sheet.getRange('G1').getValue(); // G1にプロンプトを格納想定

  for (let i = 1; i < data.length; i++) {
    const [topic, pattern, draft, status] = data[i];
    if (status === '完了' || !topic) continue;

    try {
      const response = UrlFetchApp.fetch('https://api.openai.com/v1/chat/completions', {
        method: 'post',
        headers: { 'Authorization': 'Bearer ' + apiKey, 'Content-Type': 'application/json' },
        payload: JSON.stringify({
          model: 'gpt-4o',
          messages: [
            { role: 'system', content: promptTemplate },
            { role: 'user', content: `ネタ：${topic}\n構文：${pattern}` }
          ]
        })
      });

      const result = JSON.parse(response.getContentText());
      const generatedText = result.choices[0].message.content;
      
      sheet.getRange(i + 1, 3).setValue(generatedText);
      sheet.getRange(i + 1, 4).setValue('完了');
    } catch (e) {
      sheet.getRange(i + 1, 4).setValue('エラー');
      sheet.getRange(i + 1, 5).setValue(e.message);
      MailApp.sendEmail(Session.getActiveUser().getEmail(), '【自動投稿生成エラー】', `行 ${i + 1}: ${e.message}`);
    }
  }
}
```
