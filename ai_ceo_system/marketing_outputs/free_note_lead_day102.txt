「LINE公式アカウントの友だち追加後ステップ配信シナリオ生成」に毎月どれくらいの時間を使っていますか？

実務の現場では、次のようなロスが起きやすい業務です。
・友だち追加後のステップ配信（5〜7日間分）を毎回ゼロから執筆しており、1件あたり3〜5時間のリソースが削られている

- 配信2日目以降：同様の形式で指定日数分

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const API_KEY = 'YOUR_OPENAI_API_KEY'; // 実際にはプロパティサービス等で管理を推奨

  for (let i = 1; i < data.length; i++) {
    const [target, product, days, status, result, updatedAt] = data[i];
    const rowIndex = i + 1;

    // 未処理かつ必要項目が入力されている行のみ実行
    if (status === "完了" || !target || !product) continue;

    try {
      sheet.getRange(rowIndex, 4).setValue("生成中...");
      
      // ここにOpenAI API等の外部連携処理を記述（以下はシミュレーションとエラーハンドリングの構造）
      // const generatedText = callLLMAPI(target, product, days); 
      const generatedText = "【自動生成シナリオ】\n1日目：" + target + "様へ。" + product + "の秘密を公開します...（以下略）";

      // スプレッドシートへの書き込み
      sheet.getRange(rowIndex, 4).setValue("完了");
      sheet.getRange(rowIndex, 5).setValue(generatedText);
      sheet.getRange(rowIndex, 6).setValue(new Date());

      // 完了通知メールの送信
      MailApp.sendEmail({
        to: Session.getActiveUser().getEmail(),
        subject: "【業務自動化】LINEシナリオ生成完了通知",
        body: rowIndex + "行目のシナリオ生成が完了しました。内容を確認して微調整してください。\n対象商品：" + product
      });

    } catch (e) {
      console.error("エラー発生: " + e.message);
      sheet.getRange(rowIndex, 4).setValue("エラー: " + e.message);
    }
  }
  SpreadsheetApp.getUi().alert('処理が完了しました。');
}
```
