「BtoB営業リスト抽出＆パーソナライズ文面自動化」に毎月どれくらいの時間を使っていますか？

実務の現場では、次のようなロスが起きやすい業務です。
・1件ずつ企業のWebサイトを訪問し、最新ニュースやIR情報を探して「アイスブレイク」を考える作業に膨大な時間がかかっている
・定型文の営業メールでは開封率・返信率が低迷しており、パーソナライズの必要性は感じているがリソースが足りない

1つひとつの確認作業は15分でも、積み重なると月平均で約35時間（時給2,800円換算で【年間 約1,176,000円相当】）を消費します。この記事では、ChatGPT・Geminiなどで即使える専用プロンプトだけでなく、Googleスプレッドシート上で通知・記録まで自動化するGAS完成コードもそのまま無料公開します。

■ 1. まず準備するスプレッドシート列設計（これだけで動きます）
Googleスプレッドシートの1行目（A〜F列）に以下の見出しを用意します。
【列構成】会社名 ｜ URL/企業概要 ｜ 最新ニュース・注力事業 ｜ パーソナライズ文面（自動生成） ｜ ステータス ｜ 要確認フラグ

■ 2. コピペで使える！「BtoB営業リスト抽出＆パーソナライズ文面自動化」専用・実務プロンプト
以下をそのままコピーして、対象データを貼り付けて実行してください（[要確認]フラグで人の目チェックが必要な行だけを浮き彫りにします）。

```text
あなたはBtoBアウトバウンド営業のトップセールスライターです。
以下の情報を元に、相手企業の担当者が「自社のことをよく調べてくれている」と感動するパーソナライズ文面を作成してください。

【入力情報】
- 会社名：{{会社名}}
- 最新ニュース/事業内容：{{最新ニュース/事業内容}}

【厳守判定基準】
1. 文頭の挨拶は「〇〇様の貴社Webサイトを拝見し、[具体的なニュース内容]を拝見してご連絡いたしました」から始めること。
2. ニュースの内容が「オフィス移転」「単なる人事異動」など、事業の課題解決に直結しない場合は、[要確認]フラグを立て、汎用的な事業内容への言及に留めること。
3. 相手のメリットを「弊社のサービスを導入することで、貴社の[ニュースに関連した課題]を解決できる」という文脈で100文字以内で記述すること。
4. 専門用語を多用せず、中学生でも理解できる平易な日本語を使うこと。

【出力形式】
以下のJSON形式で出力してください。
{
  "message": "生成された文面全文",
  "flag": "なし または [要確認]"
}

【[要確認]ルール】
- 最新ニュースが3年以上前のものである場合
- ニュース内容が不明瞭で、具体性に欠ける場合
- 競合他社の名前がニュースに含まれている場合
これらに該当する場合は必ずflagに「[要確認]」と記載してください。
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const API_KEY = 'YOUR_OPENAI_API_KEY';
  const API_URL = 'https://api.openai.com/v1/chat/completions';

  for (let i = 1; i < data.length; i++) {
    const [companyName, url, news, existingMsg, status] = data[i];
    if (status === '完了' || !news) continue;

    try {
      const prompt = `会社名：${companyName}\nニュース：${news}`;
      const payload = {
        model: "gpt-4o",
        messages: [
          { role: "system", content: "営業文面生成のプロンプト（ここに上記expert_promptを挿入）" },
          { role: "user", content: prompt }
        ],
        response_format: { type: "json_object" }
      };

      const response = UrlFetchApp.fetch(API_URL, {
        method: "post",
        contentType: "application/json",
        headers: { Authorization: `Bearer ${API_KEY}` },
        payload: JSON.stringify(payload)
      });

      const result = JSON.parse(response.getContentText());
      const content = JSON.parse(result.choices[0].message.content);

      sheet.getRange(i + 1, 4).setValue(content.message);
      sheet.getRange(i + 1, 5).setValue('完了');
      sheet.getRange(i + 1, 6).setValue(content.flag);

    } catch (e) {
      sheet.getRange(i + 1, 5).setValue('エラー');
      console.error(e.toString());
    }
  }

  MailApp.sendEmail({
    to: Session.getActiveUser().getEmail(),
    subject: "【自動化完了】営業リスト生成通知",
    body: "スプレッドシートのパーソナライズ文面生成が完了しました。内容を確認してください。"
  });
}
```
