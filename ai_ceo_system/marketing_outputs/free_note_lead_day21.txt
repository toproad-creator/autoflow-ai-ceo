```text
あなたは熟練のEC運営ディレクターです。以下の厳格なルールに基づき、在庫状況と競合価格から「最適な改定価格」を算出してください。

### 前提条件
- 目的：利益を確保しつつ、カート獲得率を最大化する。
- 最低利益率：販売価格の15%を死守すること。

### 判定基準
1. 在庫数が0の場合：価格改定は行わず、ステータスに「[在庫切れ]」と出力。
2. 競合価格が未入力の場合：現状維持とし、ステータスに「[競合不在]」と出力。
3. 競合価格が(仕入原価 / 0.85)を下回る場合：赤字回避のため、(仕入原価 / 0.85)を改定価格とし、ステータスに「[要確認]原価割れ注意」と出力。
4. 上記以外：競合最安値から「-10円」した価格を改定価格とし、ステータスに「[完了]自動追従」と出力。

### 出力フォーマット
JSON形式で以下の2項目のみを返してください。
- new_price: 数値（円単位、端数切り捨て）
- status_message: 文字列

### 入力データ例
SKU: PROD-001
現在庫: 5
仕入原価: 2000
競合最安値: 2800

この条件に基づき、プロフェッショナルとして正確な判断を行ってください。
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const header = data.shift(); // ヘッダー行を除去

  data.forEach((row, index) => {
    const rowIndex = index + 2; // スプレッドシートの行番号（1オリジン+ヘッダー分）
    const sku = row[0];
    const stock = row[1];
    const cost = row[2];
    const competitorPrice = row[3];

    try {
      // 簡易ロジック実装（本来はここにLLM API呼び出しや複雑な計算を挿入）
      let newPrice = 0;
      let status = "";

      if (stock <= 0) {
        newPrice = "-";
        status = "[在庫切れ]補充待ち";
      } else if (!competitorPrice || competitorPrice === "") {
        newPrice = "-";
        status = "[競合不在]維持";
      } else {
        const minPrice = Math.floor(cost / 0.85);
        const targetPrice = competitorPrice - 10;

        if (targetPrice < minPrice) {
          newPrice = minPrice;
          status = "[要確認]原価割れ回避";
        } else {
          newPrice = targetPrice;
          status = "[完了]自動追従";
        }
      }

      // シートへの書き込み
      sheet.getRange(rowIndex, 5).setValue(newPrice);
      sheet.getRange(rowIndex, 6).setValue(status);

    } catch (e) {
      console.error("Error at row " + rowIndex + ": " + e.message);
      sheet.getRange(rowIndex, 6).setValue("[エラー]システム停止");
    }
  });

  // 完了通知
  const reportTime = Utilities.formatDate(new Date(), "JST", "yyyy-MM-dd HH:mm");
  MailApp.sendEmail({
    to: Session.getActiveUser().getEmail(),
    subject: "【自動化レポート】価格改定ジョブ完了",
    body: reportTime + " 分の在庫・価格更新が完了しました。スプレッドシートを確認してください。"
  });
}
```
