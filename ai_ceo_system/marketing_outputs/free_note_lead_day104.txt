■ 2. コピペで使える！「EC・物販の在庫管理＆価格改定自動化」専用・実務プロンプト
以下をそのままコピーして、対象データを貼り付けて実行してください（[要確認]フラグで人の目チェックが必要な行だけを浮き彫りにします）。

```text
あなたはEC専門の価格戦略コンサルタントです。以下の厳格な基準に基づき、在庫商品の「改定提案価格」を決定してください。

### 前提条件
- 目標最低利益率：15%
- 競合追従ルール：競合最安値より1円安く設定する

### 判定・算出アルゴリズム
1. [利益確保の原則]: 提案価格 = MAX(競合最安値 - 1, 仕入原価 / 0.85)
2. [赤字回避アラート]: もし「競合最安値 - 1」が「仕入原価 * 1.1」を下回る場合は、競合に合わせず「仕入原価 * 1.15」を提案価格とし、ステータスに[要確認:利益薄]と付与すること。
3. [データ欠損対応]: 競合最安値が0または空欄の場合は、現在販売価格を維持し、ステータスを[競合不在]とすること。
4. [異常値検知]: 競合最安値が現在価格の50%以下、または200%以上の場合は、入力ミスの可能性があるため改定を行わず[要確認:異常値]とすること。

### 出力形式
以下の列に対応する値を、カンマ区切りのJSON配列形式で返してください。
[改定提案価格, 想定利益率, 処理ステータス]

### 入力例
SKU: A101, 原価: 5000, 競合最安値: 6500, 現在価格: 6800
出力例: [6499, 23.1, "自動改定対象"]
```

■ 3. スプレッドシート自動処理＆メール通知 GAS 完成コード
スプレッドシート上部メニューの「拡張機能」＞「Apps Script」を開き、下記のコードを貼り付けて保存してください。トリガー（毎日午前8時など）を設定すれば、確認漏れ・処理完了が自動でメール通知されます。

```javascript
function runAutoWorkflow() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = sheet.getDataRange().getValues();
  const header = data.shift(); // ヘッダー行を除去
  
  let updateCount = 0;
  let alertCount = 0;
  const now = new Date();

  try {
    data.forEach((row, index) => {
      const rowIndex = index + 2;
      const sku = row[0];
      const costPrice = parseFloat(row[2]);
      const compPrice = parseFloat(row[3]);
      const currentPrice = parseFloat(row[4]);

      if (!sku) return;

      let targetPrice, status, margin;

      // 実務的なロジック判定（簡易版）
      if (compPrice <= 0 || isNaN(compPrice)) {
        targetPrice = currentPrice;
        status = "[競合不在]";
      } else if (compPrice < costPrice * 1.1) {
        targetPrice = Math.floor(costPrice * 1.15);
        status = "[要確認:利益薄]";
        alertCount++;
      } else {
        targetPrice = compPrice - 1;
        status = "完了";
      }

      margin = (((targetPrice - costPrice) / targetPrice) * 100).toFixed(1);

      // シートへの書き込み
      sheet.getRange(rowIndex, 6, 1, 4).setValues([[
        targetPrice,
        margin,
        status,
        Utilities.formatDate(now, "JST", "yyyy-MM-dd HH:mm")
      ]]);
      updateCount++;
    });

    // 完了通知メールの送信
    MailApp.sendEmail({
      to: Session.getActiveUser().getEmail(),
      subject: "【自動通知】在庫価格改定ワークフロー完了",
      body: `処理が完了しました。\n処理件数: ${updateCount}件\n要確認アラート: ${alertCount}件\nスプレッドシートを確認してください。`
    });

  } catch (e) {
    console.error("エラー発生: " + e.toString());
    MailApp.sendEmail(Session.getActiveUser().getEmail(), "【エラー】価格改定スクリプト", e.toString());
  }
}
```
